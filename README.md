# 🦷 Family Dental Care — Clinic Management & Appointment System

A modern, responsive full-stack web application built with **Django** and **MySQL** designed to streamline dental clinic operations, patient account management, and appointment scheduling.

---

## 🌟 Key Features

* **Flexible Dual Authentication**: Users and admins can sign in seamlessly using either their **Email Address** or **Phone Number**.
* **Streamlined Patient Registration**: Quick account creation with first name, last name, email, and phone number (no explicit username required).
* **Appointment Booking & Service Integration**: Patients can book appointments directly or select a specific service directly from the home page cards to pre-fill their booking.
* **Family & Proxy Booking**: Option for authenticated users to book appointments on behalf of family members or friends.
* **Dynamic Clinic Dashboard**: Staff and administrators can manage recent appointments, update statuses (Pending, Confirmed, Completed), and review patient records.
* **Interactive Media Gallery**: Manage and showcase clinic operations, facilities, and events with dynamic image uploads.
* **Unified UI/UX**: Polished navigation headers and styled forms across all pages (Home, Booking, Login, Registration, and Admin Dashboard).

---

## 🛠️ Tech Stack

* **Backend**: Python 3.12, Django 5.2
* **Frontend**: HTML5, CSS3 (Custom responsive styling), JavaScript
* **Database**: MySQL / SQLite (Development)
* **Version Control**: Git & GitHub
